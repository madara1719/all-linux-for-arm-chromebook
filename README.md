# List 

1- postmarketOS  
postmarketOS it's a Alpine Linux based distro aimed at mobile devices and computers that no longer officially support their original OSes (or thats i think,[read about](https://postmarketos.org/)).

Pros
- Based on Alpine Linux, which means a very lightweight system
- Fairly recent kernel 
- Very good support for chromebooks 
- Friendly for low end devices (more if you use LXQt)
- Lightweight distro (based on alpine)
- Low usage of hardware
- You can build your own image with [pmbootstrap](https://wiki.postmarketos.org/wiki/Pmbootstrap)

Cons: 
- Have musl libc instead of glibc, which mean lower support for software (Appimages) 
- Isn't a linux distro "mainstream" at all, making the problem above stronger 
- Packages can be outdated or two/three versions before 
- Have BusyBox isntead of GNU coreutils, having simplified versions of the coreutils 
- Maybe not good for daily use.

2- GNU/Linux Debian (velvet-os framework)  

A very stable OS made by thousands volunteers,one of the most used distros and from which distributions such as Ubuntu, Zorin OS and Linux Mint derive. 

Pros 
- Very stable, maybe the most stable distro. 
- All (or most) software for linux works on Debian 
- One of the best pkg manager
- Low end devices friendly 
- Very used distro, which means lot of docs and support 
- Packages receive a lot of test before release 

Cons: 
- Not many people works on velvet 
- With fewer people, it takes longer to receive updates
